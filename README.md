# DevPulse — Developer Portfolio Engine

DevPulse is a high-performance developer portfolio built to showcase a full suite of client-ready web applications, micro-SaaS projects, and custom business engines.

![Status](https://img.shields.io/badge/Status-Live-success)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ Showcased Applications

- **ReservePulse**: Automated event & table booking engine with live WhatsApp routing.
- **MenuPulse**: QR digital restaurant menu engine with real-time order dispatch.
- **ClientPulse**: Drag-and-drop sales pipeline & micro-CRM interface.
- **PromptPulse**: AI prompt library and template engine for creators.
- **InvoicePulse**: PDF invoice & receipt generator with Supabase integration.
- **LeadPulse**: Agency landing page with interactive quote calculator.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Flexbox, CSS Grid, Custom Variables, Media Queries)
- **JavaScript**: Modern ES6+ (DOM Manipulation, Web Storage API)
- **Icons**: FontAwesome 6.4
